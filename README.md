# 📊 Staj Projesi - Sayaç Yönetim Sistemi

Bu proje, staj sürecim kapsamında geliştirmekte olduğum bir Sayaç Yönetim Sistemi uygulamasıdır. Proje, sayaç verilerini ve okuma kayıtlarını listeleyip yönetmeyi amaçlamaktadır.

---

## 🛠️ Kullanılan Teknolojiler

* **Backend:** .NET 8 Web API (C#)
* **Frontend:** React (Vite altyapısı ile), JavaScript, CSS
* **Versiyon Kontrol:** Git & GitHub
